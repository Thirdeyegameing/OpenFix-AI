# Security and Safety

OpenFix AI currently operates as a read-only diagnostic application.

It does not automatically:

- edit the Windows Registry
- remove or install drivers
- disable Windows services
- run repair commands that modify the system
- upload diagnostic data to Cloud AI
- use OpenAI API or another external AI API

If you find a security or privacy issue, please open a GitHub issue without including passwords, private keys, personal files, or other sensitive information.
